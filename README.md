# Drillio

Static web app untuk mengubah JSON paket soal dari AI menjadi sesi latihan pilihan ganda.

## Menjalankan lokal

```bash
npm install
npm run dev
```

## Deploy ke Cloudflare Pages

Hubungkan repository ke Cloudflare Pages lalu gunakan:

- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`

Tidak ada environment variable atau backend yang diperlukan untuk MVP ini.
